# Taskly — To-Do List App

A responsive to-do list application built with HTML, CSS, and vanilla JavaScript.

## Features
- Add tasks
- Mark tasks as complete or active
- Delete individual tasks
- Filter all, active, and completed tasks
- Clear all completed tasks
- Progress indicator and task counts
- Automatically saves tasks in browser LocalStorage
- Responsive desktop and mobile layout

## Run locally
1. Download and extract the project ZIP.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Project structure
- `index.html` — page structure
- `style.css` — styling and responsive design
- `script.js` — task management and LocalStorage logic

## Storage note
Tasks are stored in LocalStorage in the browser on the device where the app is used. Clearing browser site data may remove saved tasks.
